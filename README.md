# Ai Scripts — скрипты Aiwist для REAPER

Каталог скриптов Aiwist в одном месте. Одна ссылка в ReaPack — и в каталоге
видны все скрипты автора: обновления установленного приходят сами, новые
появляются автоматически.

## Как добавить в ReaPack

1. Установите [ReaPack](https://reapack.com), если его ещё нет.
2. В REAPER откройте *Extensions → ReaPack → Import repositories…*
3. Вставьте ссылку:

   ```
   https://github.com/Aiwist/ai-scripts/raw/main/index.xml
   ```

4. Нажмите *OK*, затем *Extensions → ReaPack → Browse packages*, найдите
   нужный скрипт и установите.

Дальше ReaPack сам проверяет обновления при синхронизации. Новые скрипты
становятся видны в каталоге — добавлять новые ссылки не нужно.

## Что доступно

**[Ai Transcriber](https://github.com/Aiwist/ai-transcriber)** — превращает
выделенное аудио в MIDI прямо в проекте REAPER: ноты появляются на дорожках
под исходником, их можно править и играть виртуальными инструментами.
Обработка идёт локально, на видеокарте или процессоре.
