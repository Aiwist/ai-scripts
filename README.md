# Ai Scripts — общий индекс ReaPack

Единая точка входа для скриптов Aiwist в REAPER. Пользователь добавляет одну
ссылку в ReaPack и получает все скрипты автора: обновления установленного
приходят сами, новые скрипты появляются в каталоге.

## Ссылка для ReaPack

```
https://raw.githubusercontent.com/Aiwist/ai-scripts/main/index.xml
```

ReaPack → **Manage repositories** → правый клик → **Add repository** →
вставить ссылку → OK → **Synchronize packages**.

## Что внутри

В этом репозитории лежит только `index.xml` — каталог пакетов. Сами скрипты
остаются в своих репозиториях, ссылки в `<source>` абсолютные и привязаны
к тегам выпусков.

| Категория | Пакет | Репозиторий |
|---|---|---|
| Transcriber | `Aiwist_Transcriber.lua` | [Aiwist/ai-transcriber](https://github.com/Aiwist/ai-transcriber) |

Имя индекса — **Aiwist**. Оно задаёт папку установки в REAPER
(`Scripts/Aiwist/<категория>/<файл>`), поэтому менять его нельзя без причины:
смена имени переносит действия в другую папку и сбрасывает привязки
к горячим клавишам.

## Как обновлять индекс

Индекс собирается из индексов отдельных проектов, а не пишется руками.
Порядок при выпуске нового скрипта или новой версии:

```bash
# 1. в проекте скрипта собрать его собственный индекс
cd "../Ai Transcriber" && python tools/reapack.py prepare

# 2. здесь пересобрать общий индекс
cd "../ai-scripts" && python tools/build_index.py "../Ai Transcriber/index.xml"

# 3. проверить ссылки и закоммитить
git add index.xml && git commit -m "Индекс: Ai Transcriber <версия>" && git push
```

Для нового скрипта его `index.xml` просто добавляется в команду сборки,
а скрипт пишет свою категорию в своём репозитории.

Скрипт `tools/build_index.py` отказывается собирать индекс, если две категории
называются одинаково, — это защита от конфликта путей установки.

## Требования к проекту-источнику

- Публичный репозиторий с тегами вида `v<версия>` и GitHub Release.
- Собственный `index.xml`, где `<source>` указывает на файлы по тегу.
- Имя индекса проекта не важно: в общий попадают категории, а имя задаёт этот
  репозиторий.
