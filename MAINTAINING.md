# Служебная инструкция: как собирается индекс

Для пользователя эта страница не нужна — ему достаточно ссылки из `README.md`.
Здесь — как поддерживать общий индекс `index.xml` и что в нём нельзя менять.

## Что внутри

`index.xml` — только каталог пакетов. Сами скрипты лежат в своих репозиториях,
ссылки в `<source>` абсолютные и привязаны к тегам выпусков (`v<версия>`),
поэтому версия, которую видит пользователь, всегда совпадает с GitHub Release.

| Категория | Пакет | Репозиторий |
|---|---|---|
| Transcriber | `Aiwist_Transcriber.lua` | [Aiwist/ai-transcriber](https://github.com/Aiwist/ai-transcriber) |

Имя индекса — **Aiwist**. Оно задаёт папку установки в REAPER
(`Scripts/Aiwist/<категория>/<файл>`). Смена имени перенесёт действия в другую
папку и сбросит привязки к горячим клавишам — не менять без причины.

## Как обновлять

Индекс собирается из индексов отдельных проектов, а не пишется руками.

```bash
# 1. в проекте скрипта собрать его собственный индекс
cd "../Ai Transcriber" && python tools/reapack.py prepare

# 2. здесь пересобрать общий индекс
cd "../ai-scripts" && python tools/build_index.py "../Ai Transcriber/index.xml"

# 3. проверить и закоммитить
git diff index.xml
git add index.xml && git commit -m "Индекс: Ai Transcriber <версия>" && git push
```

Проверка без записи файла:

```bash
python tools/build_index.py --check-only "../Ai Transcriber/index.xml"
```

## Новый скрипт в индексе

1. В репозитории нового скрипта настраивается своя сборка индекса — она создаёт
   `index.xml` с собственной категорией, ссылками на тег и манифестом.
2. В команду сборки выше добавляется путь к его индексу:

   ```bash
   python tools/build_index.py "../Ai Transcriber/index.xml" "../<новый проект>/index.xml"
   ```

3. Результат коммитится и отправляется здесь. Пользователям ничего добавлять
   не нужно: при следующей синхронизации ReaPack увидит новую категорию.

## Защита от ошибок

- `build_index.py` отказывается собирать индекс, если две категории называются
  одинаково: это конфликт пути установки в REAPER.
- Ссылка на индекс проекта (`ai-transcriber/index.xml`) наружу не публикуется.
  Если человек добавит и её, и общий индекс, ReaPack увидит один и тот же пакет
  из двух источников.
- Имя пакета и имя главного файла (`Aiwist_Transcriber.lua`, `main`) менять
  нельзя: от них зависят существующие действия и горячие клавиши.

## Требования к проекту-источнику

- Публичный репозиторий с тегами вида `v<версия>` и GitHub Release, где лежат
  вложения, на которые ссылается индекс.
- Собственный `index.xml`, собранный сборкой проекта, с `<source>` по тегу.
